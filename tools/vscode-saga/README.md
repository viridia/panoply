# SAGA for VS Code

Syntax highlighting for `.saga` files, Panoply's scripting language.

Install it from this folder with **Developer: Install Extension from Location...** in the command
palette, then reload the window. VS Code loads it from here, so edits to the grammar take effect
on the next reload. A folder linked or copied into `~/.vscode/extensions` is not enough: VS Code
loads only the extensions its registry lists.
